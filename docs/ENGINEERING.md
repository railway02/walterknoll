# 实现说明

本轮按用户要求使用最直接的方式写静态网页，降低视觉和代码复杂度。

- 内容放在 HTML：打开文件就能找到产品、文章和门店，不用先追踪数据请求。
- 样式用普通 CSS：系统字体、居中页面、简单卡片和一个主要窄屏布局规则。
- 交互用事件监听：点击切图、分类隐藏、分页、色卡和表单提示。
- FAQ 使用原生 details/summary；导航保持普通链接，在手机上自然换行。
- 导航和页脚仍从同一份片段同步，避免十页地址不一致。同步只是开发工具，用户打开网页时不执行。
- Playwright、链接检查和静态服务是开发工具，保留以便检查十页改动；网页不依赖这些工具运行。

当前实现没有框架、构建、后端、模块、运行时 JSON 请求、收藏或全站弹窗。assets/data/catalog.json 和未用到的图片作为原始资料保留，不再参与页面渲染。

完整旧版保存在 Git 历史与 backup/polished-20261015 分支。入门版独立提交，验证记录只描述实际执行过的检查。
