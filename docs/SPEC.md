# Walter Knoll 入门静态版范围 v2

2026-10-15：用户要求将原来过于成熟的实现调整到刚学习网页开发的水平，并明确为静态网页。本轮范围取代 v1 的高保真和复杂交互要求。

## 保留

- 原生 HTML、CSS、JavaScript；A–E 五组、十个页面及现有目录。
- 品牌主题、现有本地素材、来源链接、所有页面之间的正常跳转。
- 基础练习：手动轮播、单条件分类、两页切换、原生 FAQ、色卡、门店查询、表单验证。
- 小屏幕能阅读，基本标签与键盘操作可用。

## 简化

- 1000px 居中白色内容区、灰色背景、系统字体、普通链接、基础卡片。
- 顶部普通换行导航，页脚为文字链接；移除固定顶栏与移动端抽屉。
- 页面内容直接写在 HTML，用普通 defer 脚本操作现有元素。
- 移除模块、运行时 JSON 请求、统一卡片渲染接口、收藏、全站搜索、详情弹窗和自动轮播。
- 不使用框架、构建步骤、后端或第三方 API；双击 index.html 可以运行。

## 验收

十页在 file:// 和本地 HTTP 下可访问。桌面 1440px、手机 390px 无横向溢出、无裂图和脚本异常。链接与锚点正常，基础交互产生可见结果，关闭 JavaScript 后主体内容仍可阅读。

联系与订阅只演示浏览器验证和本地提示，不发送或保存个人信息。不编造产品、材料或可持续数据。
